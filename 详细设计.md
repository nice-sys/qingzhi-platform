## 2. 公共底座详细设计（Common Infrastructure）

### 2.1 统一响应封装 `Result<T>`

**位置**：[common/Result.java](../backend/src/main/java/com/qingzhi/demo/common/Result.java#L1-L133)

```java
public class Result<T> implements Serializable {
    private Integer code;     // 1=SUCCESS，其他=失败枚举
    private String  message;  // 面向用户的提示文案
    private T       data;     // 业务数据；成功时必填，失败时通常 null

    // 静态工厂
    Result.success() / success(T) / success(String msg, T)
    Result.fail()    / fail(ResponseCodeEnum) / fail(code, msg)
    boolean  isSuccess()
}
```

- 全局使用：所有 Controller 方法返回 `ResponseEntity<Result<?>>` 或直接 `Result<?>`。
- 前端 `request.js` 解包：`code=1` → `resolve(data)`；其他 → `reject({code,message})`。

### 2.2 统一分页封装 `PageResult<T>`

**位置**：[common/PageResult.java](../backend/src/main/java/com/qingzhi/demo/common/PageResult.java#L1-L40)

```java
public class PageResult<T> {
    private List<T> list;

    private Integer pageNum;
    private Integer pageSize;
    // Builder：PageResult.of(list, total, pageNum, pageSize)

```

- 前端 `<Pagination>` 组件只认该结构，禁止各页面自行拼装分页字段。

## 3. 横切安全详细设计（Security & AOP）

### 3.1 JWT 生命周期

**位置**：[utils/JwtUtil.java](../backend/src/main/java/com/qingzhi/demo/utils/JwtUtil.java#L1-L100) · [config/JwtConfig.java](../backend/src/main/java/com/qingzhi/demo/config/JwtConfig.java#L1-L30) · [interceptor/JwtInterceptor.java](../backend/src/main/java/com/qingzhi/demo/interceptor/JwtInterceptor.java#L39-L119)

#### 3.1.1 签发（登录成功后）

```
JwtUtil.generateToken(uid=Long, role=Integer)
  ├─ Header: { alg: HS256, typ: JWT }
  ├─ Claims: {
  │   "uid":  Long
  │   "role": Integer    (0=Admin 1=Teacher 2=Student)
  │   "iat":  Instant.now().epochSecond
  │   "exp":  iat + 24*3600s      ← 24h 过期
  │  }
  └─ Signature: HMAC-SHA256(Header.Claims, Base64(secret))
       secret = JwtConfig.secret  (生产用环境变量 QINGZHI_JWT_SECRET 覆盖)
```

#### 3.1.2 解析（Interceptor.preHandle）

```pseudo
步骤 1：判断是否白名单（WebConfig.getWhitelist() = /auth/**, /file/download/**, /resource/list, /resource/courses, /resource/stats, /actuator/**, /error）
        → 是：return true 完全跳过
步骤 2：判断"公开 GET 匿名放行" isPublicGet()
        请求方法=GET  AND (
            requestURI ∈ {"/resource/list", "/resource/courses", "/resource/stats"}
            OR requestURI 正则 matches("^/resource/\\d+$")
        )
        → 是：若没有 Authorization 头 OR parseJwt 抛 Exception → 仍然 return true 匿名通过（userId=null 交给 Service 过滤可见性）
步骤 3：必须鉴权
        Authorization = Bearer <token>?  缺失 → 1001
        Jwts.parserBuilder(secret).parseClaimsJws → success?
            → NO（过期/签名错/格式错）→ 1001
            → YES：request.setAttribute(REQUEST_ATTR_CURRENT_USER_ID,   Long uid)
                   request.setAttribute(REQUEST_ATTR_CURRENT_USER_ROLE, Integer role)
                   return true
```

#### 3.1.3 Controller 端取值（静态方法，避免重复 request.getAttribute 样板）

```java
// 在 JwtInterceptor 内：
public static Long    getCurrentUserId()   { return (Long)    request.getAttribute(ATTR_UID);  }
public static Integer getCurrentUserRole() { return (Integer) request.getAttribute(ATTR_ROLE); }
```

### 3.3 限流切面 `@RateLimit` + AOP

**位置**：[annotation/RateLimit.java](../backend/src/main/java/com/qingzhi/demo/annotation/RateLimit.java#L1-L30) · [aspect/RateLimitAspect.java](../backend/src/main/java/com/qingzhi/demo/aspect/RateLimitAspect.java#L45-L97)

#### 注解参数
```java
public @interface RateLimit {
    int limit();            // 窗口内最大次数，例 6
    int windowSeconds();    // 窗口秒数，例 60
    String keyFrom() default "userId";  // "userId" 按登录用户，"ip" 按 IP
}
```

#### 切面实现（滑动窗口）
```pseudo
@Around 切点：@annotation(rateLimit)
  key = if keyFrom=userId -> currentUid else -> clientIp
  now = System.currentTimeMillis()
  windowMs = windowSeconds*1000
  (Thread-safe) 取 concurrentMap[key] -> 队列<long timestampMs>
    removeAll timestamps where now - ts > windowMs
    if queue.size >= limit:  throw BusinessException(UPLOAD_RATE_LIMITED 5003)
    else: queue.add(now), ProceedingJoinPoint.proceed()
```

- 使用：`FileController.upload()` 顶上加 `@RateLimit(limit=6, windowSeconds=60, keyFrom="userId")`

### 4.2 核心方法时序：`POST /auth/login`

```
Client → AuthController.login(LoginRequest) [@PostMapping("/login")]
  │  Controller:  @Valid LoginRequest req
  ▼
AuthServiceImpl.login(req)
  (1) userMapper.selectByUsername(req.username) → User?
  (2) BusinessException.throwIfNull(user, ACCOUNT_OR_PASSWORD_ERROR 2002)
  (3) if user.status == LOCKED 且 NOW - user.lockTime < 30min
         → throw 2003 ACCOUNT_LOCKED
  (4) if PasswordUtil.md5(req.password) != user.password
         → login_fail_count + 1
            count >= 5 ?  user.status=LOCKED user.lockTime=NOW()  userMapper.update(user); throw 2003
                              :  userMapper.update(user);             throw 2002
  (5) 成功：user.login_fail_count=0 userMapper.update(user)
  (6) token = JwtUtil.generateToken(user.id, user.role)
  (7) return LoginResponse(token, user→UserInfoResponse)
Controller: Result.success(LoginResponse)
```

```
+ resolveFile(relative):

    if (!Files.exists(abs)) throw FILE_NOT_FOUND 5005;
```

```
  3 遍历 rows (idx 从 0 开始 2 实际 Excel 行 2+n):
      a. 字段校验：学号不能为空 → fail(rowIndex=N, field="学号", msg="学号不能为空")
      b. 密码生成 = 默认学号后 8 位，不满足规则 → `Default1a` 强制合规
      c. 查重 selectByUsername(row.stuno) → exist? fail("账号已存在")
      d. 以上 ok → batchInsertBuffer.add(User.of(row, PasswordUtil.md5(defaultPwd)))
    当 buffer 达到 200 → mybatis batch insert one shot; total += success
  4 flush remaining
  5 return ImportResultResponse(total, successCount, failCount, rowErrors[]:List<ImportRowError>)
```

- **MVP 策略**：部分成功（非全事务回滚，符合 BR-AD05 错误明细优先）。

```
① Request Interceptor:

② Response Interceptor (Happy Path 2xx):
```
